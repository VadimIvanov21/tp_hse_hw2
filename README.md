# tp_hse_hw2


## Приложение для создания и управлениями рецептами

Консольное приложение для создания рецептов, масштабирования порций и генерации списка покупок.



### Установка

```bash
git clone https://github.com/VadimIvanov21/tp_hse_hw2.git
cd tp_hse_hw2
pip install -r requirements.txt
```

### Использование

```bash
python recipes.py
```

### Тесты

```bash
pytest
```
